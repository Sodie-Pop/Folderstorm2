Website: [folderstorm.com](https://folderstorm.com) — Support: [folderstorm.com/help](https://folderstorm.com/help/) — Bug reports: [folderstorm.com/bugs](https://folderstorm.com/bugs/) — Privacy: [folderstorm.com/privacy](https://folderstorm.com/privacy) — Early development (0.x).

**Install:** download the `-windows-x64.zip` below, unzip it in a folder you can write to (not `C:\Program Files`) and start `Folderstorm2.exe`. It then updates itself. The build is not code-signed yet: Windows may show "Windows protected your PC" (More info › Run anyway). The `-symbols.zip` is only for crash analysis.
